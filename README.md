# Приложение для анализа вакансий.
Приложение для работы с вакансиями, которое позволяет:
Получать вакансии с сайта hh.ru через API.
Фильтровать и сортировать вакансии по ключевым словам и зарплате.
Сохранять вакансии в JSON-файл.
Взаимодействовать с пользователем через консоль.

## Оглавление.
1. Установка
2. Использование
3. Структура проекта
4. Тестирование
5. Лицензия

### Установка.
1. Клонируйте репозиторий:
  https://github.com/vadbarriens/Course_project_2
2. Установите зависимости:
  pip install -r requirements.txt
3. Откройте проект в PyCharm:
  - Запустите PyCharm.
  - Выберите Open и укажите путь к папке проекта.
  - Убедитесь, что интерпретатор Python настроен (PyCharm обычно предлагает настроить его автоматически).

### Использование.
Запуск приложения.
Откройте файл main.py в PyCharm.
Нажмите Run (или используйте сочетание клавиш Shift + F10).
Следуйте инструкциям в консоли:
Введите поисковый запрос (например, "Python Developer").
Укажите количество вакансий для вывода (например, 10).
Введите ключевые слова для фильтрации (например, "Django Flask").
